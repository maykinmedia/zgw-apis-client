About
=====

A Python client library for interacting with the `ZGW APIs <https://vng-realisatie.github.io/gemma-zaken/>`_.

Introduction
============

ZGW APIs Client is a strongly typed HTTP client library for the APIs implementing the
ZGW APIs standard. For installation and usage instructions, see the
`documentation <https://zgw-apis-client.readthedocs.io/en/latest/?badge=latest>`_.

Installation and usage
======================

See the `docs <https://zgw-apis-client.readthedocs.io/>`_.
